# 📊 RTL Accessible Financial Dashboard

A modern, responsive Financial Dashboard built with pure HTML5 and CSS3 (RTL support). This project was created as a foundational milestone with a primary focus on **SEO Best Practices** and **Web Accessibility (a11y)**.

---

## ✨ Key Features & Focus Areas

### ♿ Accessibility (a11y)
* **Semantic HTML5 Markup:** Proper use of landmark tags (`<main>`, `<nav>`, `<aside>`, `<section>`, `<table>`, etc.).
* **Color Contrast:** High contrast ratios adhering to WCAG guidelines using CSS OKLCH color spaces.
* **Responsive & Scrollable Tables:** Accessible data presentation for small screens with custom horizontal scrollbars.

### 🔍 SEO Optimization
* Structured content flow allowing search engine crawlers to properly index page hierarchy.
* Clean, lightweight HTML/CSS structure with zero external bloated JavaScript libraries for fast loading speeds.

### 🎨 Design & Layout
* **RTL First:** Native support for Arabic and right-to-left layout dynamics.
* **Modern CSS Grid & Flexbox:** Flexible and layout-driven architecture.
* **Interactive Components:** Flip CSS cards for payment methods and interactive hover states.

---

## 🛠️ Built With

* **HTML5** (Semantic Architecture)
* **CSS3** (Custom Properties, CSS Grid, Flexbox, Media Queries)
* **Design Pattern:** Mobile-First & Responsive Breakpoints (640px, 768px, 992px)
